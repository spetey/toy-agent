Semantics

Cells are 16-bit Hamming(16,11) words: 11 payload bits, 5 parity bits. The op is chosen from the raw payload by the [11,6,4] opcode code: one flipped payload bit still gives the same op, two give a no-op, and parity bits never affect fetch. Each step executes tape[p] then p += 1. < > { } B A move a, b, ix by one - + payload of tape[a] −1 / +1 (parity kept valid) Q P the same on tape[b] . tape[b] ^= tape[a] , tape[a] ^= tape[b] (raw 16 bits; no-op if a = b) m tape[a] ^= tape[ix] I tape[a] ^= syndrome5(tape[ix]) V tape[a] ^= 1 << syndrome4(tape[ix]) j tape[ix] ^= tape[a] (no-op if a = ix) [ if payload(tape[a]) ≠ 0: jump to matching ] ] if payload(tape[a]) ≠ 0: jump to matching [ ( ) the same, testing tape[b]; own matching stack A block enters only when the tested cell is zero and repeats while it is nonzero. A ~ cell (payload 2047) is a barrier: brackets never pair across it. A write to the IP's own cell is a no-op. Every step is a bijection, so back is deductive.
