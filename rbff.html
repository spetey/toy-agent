Semantics

Each step executes tape[p], then p += 1 (always, even after a jump, so a jump lands one past the partner bracket). All of p, a, b wrap modulo the tape size. [ if tape[a] ≠ 0: jump to matching ] — enter the body only when zero ] if tape[a] ≠ 0: jump to matching [ — repeat the body while nonzero Guards: a write to tape[p] is a no-op; an xor with a = b is a no-op; an unmatched bracket is a no-op. With these, every step is a bijection, so back needs no history: it decrements p, reads the op there, and applies its inverse.
